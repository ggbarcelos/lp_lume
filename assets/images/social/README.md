# Artes para compartilhar o Lume

| Arquivo | Dimensões | Uso |
| --- | --- | --- |
| `lume-share-1200x630.jpg` | 1200 × 630 | Prévia principal de links no LinkedIn, Facebook e WhatsApp |
| `lume-linkedin-1200x627.jpg` | 1200 × 627 | Publicação horizontal no LinkedIn |
| `lume-square-1080x1080.jpg` | 1080 × 1080 | Publicação quadrada e imagem alternativa Open Graph |
| `lume-feed-1080x1350.jpg` | 1080 × 1350 | Publicação vertical no feed |
| `lume-status-1080x1920.jpg` | 1080 × 1920 | Stories e Status do WhatsApp |

O `index.html` usa a arte horizontal como primeira imagem Open Graph e como imagem do cartão Twitter. A quadrada é uma alternativa; cada plataforma decide qual imagem utilizar. As versões de feed e Status são arquivos para publicação manual.

URL configurada: **https://lume.glauberbarcelos.com.br/**. A página e as imagens precisam estar publicadas e acessíveis sem autenticação nesse domínio para que as plataformas obtenham as prévias. Plataformas podem manter prévias antigas em cache.

As artes foram criadas com a ferramenta integrada de geração de imagens, usando as logos reais do Lume e do Lume Force como referências. As telas representam visualmente a proposta do produto. Os prompts estão em [PROMPTS.md](PROMPTS.md).
