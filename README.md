# Lume — landing page

Landing page estática para apresentar o Lume e o Lume Force, explicar a conexão entre os aplicativos e contextualizar a rede de proteção no Rio Grande do Sul.

## Visualização

Abra `index.html` no navegador. A página usa HTML, CSS e JavaScript sem etapa de build; imagens e logos ficam em `assets/images`. A fonte Sora e DM Sans é carregada do Google Fonts.

## Conteúdo e demonstração

- A demonstração das telas é conceitual: não envia SOS nem aciona atendimento.
- Dados do Rio Grande do Sul e limites de cobertura estão descritos na página, com links para as fontes.
- `REVISAO_CONTEUDO.md` registra o escopo da revisão editorial e a checagem de afirmações sobre o produto.
